Byte for byte

Every .cmz file ends with a checksum of the original. Unpacking checks it, so a damaged file is reported instead of quietly handed back wrong.

Your originals stay put

The .cmz goes next to the source as a new file, and cmz never writes over anything. If a name is taken, it saves as “name (2)”.

Unpacking is always free

No key, no trial, no internet needed to get your files back. Every new version of cmz opens every older .cmz file.

Size and speed, side by side

What the extra time buys

cmz looks at your data much more closely than a zip program does. That is why its files are smaller, and it is also why it takes longer. The time is spent once, when you pack; the space is saved for as long as you keep the file. That suits photo libraries, finished projects, backups and observation archives. For files you send every few minutes, 7-Zip is the quicker tool.

Under the hood

How cmz gets there

Only the outline; the details stay in the workshop for now.

  • Many models, one voteMany small models each predict the next bit of your file from a different point of view, and cmz blends their predictions. This family of methods is called context mixing. Unpacking has to repeat the same predictions, so it is not much faster than packing.
  • Undo, then packJPEG photos, MP3s and the deflate streams inside zip, PDF and Office files are first decoded exactly. cmz packs what they contain, and on unpacking rebuilds the original file bit for bit.
  • Knows FITScmz reads the FITS header to learn how an image is laid out. Raw camera frames go through a separate, fast image coder, which is why they pack in seconds.

How it works for you

Three clicks, nothing to learn

  1. Choose files

    Right-click files or a folder in Explorer and pick Compress with cmz, or drop them on the window.

  2. Get the .cmz

    Each file gets its own .cmz next to it. The list shows the new size, the ratio and the time for every file.

  3. Open it again

    Double-click a .cmz file and the original is back where it was, identical to the last byte.

There is no installer. On first start cmz offers to install itself for your user account: a Start menu entry, the Explorer menu and the .cmz file type. It needs no administrator rights, and Windows Settings → Apps removes it again.

Questions

FAQ

Is it really lossless?

Yes. The unpacked file is identical to the original, bit for bit, and every .cmz carries a checksum to prove it. A JPEG stays the same JPEG, an MP3 the same MP3. (For astronomers there is an optional lossy mode for floating-point images, off by default and clearly marked.)

What can't cmz shrink?

Videos (MP4, MKV), 7z and RAR archives, most installers and encrypted files are already packed as tightly as they go, so they stay about the same size with any tool. In our test a RAR archive 100.0% (7-Zip 100.0%); an MSI installer 99.1% (7-Zip 99.6%); an EXE installer 99.8% (7-Zip 99.8%).

Will future versions open my files?

Yes. Each new version keeps the code for every older format. If an older cmz meets a file made by a newer one, it says so and asks you to update. It never guesses.

Does it need the internet?

No. The beta works fully offline, and unpacking never needs a connection.

Windows says “Windows protected your PC”. Is that normal?

During the beta the program is not code-signed yet, so SmartScreen warns about a new publisher. Choose “More info”, then “Run anyway”. To check that your copy is the original, compare its SHA-256 checksum (PowerShell: Get-FileHash cmz-1.0-beta.exe) with this one:

5e263ef29ce5b2ff5fa430ea339bc40fbb8aed0f0c928d7873bc4880dc1c5d07

Can I pack a whole folder into one file?

Not in this version. A folder is packed file by file, and each file gets its own .cmz.

Which Windows versions are supported?

64-bit Windows 10 and 11.
