Download and check

Get the same files

The script makes a folder called cmz-test-files, downloads each file from the address in the list and prints OK or DIFFERENT for each one. Files that are already there and match are skipped, so you can run it again at any time.

Windows

Save get-test-files.ps1, then run it in PowerShell from the same folder:

powershell -ExecutionPolicy Bypass -File .\get-test-files.ps1

Tested on Windows 11. It is written to run on Windows 7 too, with the PowerShell that comes with it. A Windows 7 without updates may not be able to open the secure (TLS 1.2) connections most of these sites require; the script then says so, and Windows Management Framework 5.1 from Microsoft fixes it.

Linux, macOS, Git Bash

Save get-test-files.sh, then run:

bash get-test-files.sh

Needs curl, sha256sum or shasum, and unzip or bsdtar.

The files take 64.5 MB. The script downloads about 125.4 MB, because sao comes out of the 68 MB Silesia corpus zip, which it deletes afterwards.

Notes

Why some links look the way they do

  • Fixed versions. The ONLYOFFICE samples and the three files from GitHub repositories (CSV, JSON, log) are linked at a fixed commit, so they cannot change under you. The airport-codes CSV, for example, is updated every day.
  • The DSS image. The Digitized Sky Survey server makes the cutout on request and writes the download date into the FITS header. The image data itself is the same every time. The script writes back the date of our copy (2026-10-27), so the checksum matches. For a copy downloaded by hand, this PowerShell line does the same: 
    $p='dss_orion_10arcmin.fits'; $b=[IO.File]::ReadAllBytes((Resolve-Path $p).Path); [Text.Encoding]::ASCII.GetBytes('2026-10-27').CopyTo($b,491); [IO.File]::WriteAllBytes((Resolve-Path $p).Path,$b)
  • If a file shows DIFFERENT. A publisher may update a file, as Project Gutenberg sometimes does. The results on this page belong to the version with the checksum shown here.
  • Rights. Every file stays under its publisher's terms. We only link to it.
  • Your results. If you run another compressor on these files, we would like to hear about it, good news or bad: fmolnar.no1@gmail.com.
